# Network Stress Protocol

## Laboratory Network Profiles
| Profile | Download | Upload | RTT Latency | Target Scenario |
|---|---:|---:|---:|---|
| Fast Mobile | 10 Mbps | 5 Mbps | 40 ms | Prime 4G / 5G |
| Moderate | 3 Mbps | 1 Mbps | 100 ms | Average 4G |
| Slow 4G | 1.6 Mbps | 750 Kbps | 150 ms | Standard Lighthouse simulation |
| Very Slow | 400 Kbps | 200 Kbps | 300 ms | 3G / Congested Cell |
| Extreme Edge | 150 Kbps | 75 Kbps | 600 ms | Deep Edge / Congested Cell |
| Severe Stall | 100 Kbps | 50 Kbps | 800 ms | Survival Floor |

## Stress Metrics
- FCP & LCP under throttled conditions.
- Zero blank-screen timeouts.
- Server-rendered HTML text and critical headings immediately legible before JS downloads.
