# Forensic Performance Lab (`forensic-performance-lab`)

- `browser-tracing.md` — Chrome Performance tracing, Long Tasks / LoAF profiling, stack frame attribution.

- `visual-readiness.md` — Filmstrip analysis, blank screen duration vs interactivity gap.
- `regression-policy.md` — Zero-regression verification across 46+ test suites, types, and SEO contracts.
- `acceptance-gates.md` — 5-Gate scientific acceptance (Causal Evidence, Correctness, Measured Improvement, No Functional Regression, No Visual Regression).
