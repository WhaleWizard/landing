# Low-End Devices Protocol

## Emulation Matrix
- **CPU Throttling**:
  - 1x (Desktop baseline)
  - 4x (Moto G4 standard mobile benchmark)
  - 6x (Low-end budget mobile benchmark)
- **Memory Pressure**:
  - Heap snapshot profiling before and after route navigation.
  - Verification that event listeners, IntersectionObservers, and animation frames are properly cleaned up on unmount.
