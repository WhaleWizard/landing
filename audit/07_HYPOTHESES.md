# REGISTER OF TECHNICAL HYPOTHESES & ROOT CAUSE EXPERIMENTS

| **HYP-001** | Initial cold load is delayed by loading all public route modules eagerly | Large total bundle size in build output (1.47 MB uncompressed) | Route inspection reveals dynamic imports via `createStaticRouter`, lazy components, and separate Vite chunks. Initial critical JS is ~90.8 kB gzip. | Network waterfall capture across cold start in Playwright | Only current route hero and critical chunks requested on cold load | Only index chunk and target route chunk downloaded prior to scroll; deferred sections load sequentially on scroll | **DISPROVEN / RESOLVED**: Initial payload is partitioned; deferred sections use sequential warmup and viewport rootMargin. |
| **HYP-002** | Meta Apps Hero animations fail due to missing JS runtime animation libraries | Page has complex receipt angle visual and custom layout | Component `HeroTitleEffect.tsx` uses pure CSS keyframe animations triggered by DOM mount without third-party JS animation engines. | DOM and computed CSS style inspection; sharp pixel rendering analysis | Animated text renders visible characters with gradient | Characters were transparent due to CSS stacking context and inheritance (`background-image: inherit` broken by intermediate wrapper) | **DISPROVEN & RESOLVED**: Root cause was CSS stacking context & Blink timing quantization, resolved in `hero-title-effects.css` and `HeroTitleEffect.tsx`. |
| **HYP-003** | Wide desktop screens (>1920px) suffer from layout shifts and horizontal overflow | Unbounded flex/grid layouts on ultrawide monitors | Layout uses Tailwind `max-w-7xl` or `max-w-5xl` with `mx-auto` centering and fluid margins | Multi-viewport automated testing at 1920x1080 and 2560x1440 | 0px horizontal overflow, stable centered layout | `document.documentElement.scrollWidth === window.innerWidth` across all 27 routes | **DISPROVEN**: Layout is 100% stable at 1920px and 2560px. |
| **HYP-004** | Cloudflare edge 301/308 redirects cause latency spikes on navigation | Some internal links previously lacked canonical trailing slashes | Internal navigation is client-side via React Router 7 (`<Link to="...">`), which does not trigger HTTP round-trips | Network request monitoring during navigation | Zero edge HTTP redirects during SPA transitions | All internal links canonicalized to trailing slashes; zero edge 308 redirects | **RESOLVED**: Canonical links enforced by tests. |
| **HYP-005** | Circular dependencies detected by Madge cause undefined export runtime crashes | Madge reports 8 circular dependency loops in `src/main.tsx` | App mounts and runs without runtime crashes in tests | AST inspection of the 8 circular cycles | Verify whether cycles execute at import time or inside lazy function calls | Cycles (e.g. `useFaqContent.ts <-> FAQPage.tsx`, `Hero.tsx <-> heroPreload.ts`) involve type imports and lazy loading, but represent architectural coupling hazards | **CONFIRMED ARCHITECTURAL HAZARD**: Circular dependencies must be decoupled to prevent bundling hazards. |
| **HYP-006** | ESLint `react-hooks/exhaustive-deps` warnings in `Admin.tsx` and `BlogPage.tsx` lead to stale closures | 13 hook warnings flagged by ESLint | Code relies on component re-mounts or outer state | Code inspection of line numbers flagged by `eslint` | Hook callbacks and effects contain missing/unnecessary dependencies | `BlogPage.tsx:672` missing `returnTo`, `Navbar.tsx:208` unnecessary `location.key` | **CONFIRMED CODE DEFECT**: Stale closures or redundant recreations present; needs surgical fix. |
| **HYP-007** | Axe-core accessibility violation `[moderate] region` in static root shell | Axe-core flags 1 violation on `dist/index.html` | Page has header, main, and footer elements | DOM inspection of landmarks in pre-rendered static HTML shell | All top-level visible content wrapped in `<header>`, `<main>`, or `<footer>` | Static shell or floating overlays have elements outside landmark regions | **CONFIRMED A11Y DEFECT**: Need landmark wrapping for all top-level content. |
