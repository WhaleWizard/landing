## Часть 1. Что исправлено — по цене ошибки

### Дороже всего

**1. В статьях не работали 34 из 49 разрешённых атрибутов** · `85dc951`

Санитайзер вырезал атрибуты, которые сам же числил разрешёнными: своя строгая
регулярка для адресов применялась ко **всем** атрибутам, а не только к
ссылочным. Не работали: `colspan`/`rowspan` (таблицы разъезжались), `viewBox`,
`d`, `fill`, `stroke` (SVG выходил пустым прямоугольником), `controls`, `loop`,
`muted` (плеер без кнопок), `allow`, `allowfullscreen` (YouTube без полного
экрана), `width`, `height`, `loading`, `srcset` (сдвиг вёрстки, нет ленивой
загрузки), `target` («открыть в новой вкладке»).

Проверено в браузере: было мертво 34, стало 0. Отдельно — 16 попыток обхода
(скрипты, `onerror`, `onload` на svg, `javascript:`, `data:text/html`, чужой
iframe, `form`, `object`, `base`, `onclick`): всё вырезается как раньше.

Заодно закрыт двойной разбор разметки в `BlogPage`.

**2. Enter на кнопке «Отмена» подтверждал действие** · `447282c`

Диалог ловил Enter обработчиком на документе, независимо от фокуса. Обработчик
срабатывал первым: действие подтверждалось, клик по «Отмене» уже ничего не
менял. Через этот диалог удаляются карточки клиентов и чистится корзина заявок.

**3. Отметка задачи уходила не в тот день** · `c9b4e2c`

Планер считает дни по местному календарю, сервер — по UTC. Для Ташкента в
04:00 понедельника отметка уходила в **воскресенье прошлой недели**.

**4. Выгрузка воронки могла запустить формулу в Excel** · `2f29c5c`

UTM-метку задаёт кто угодно ссылкой; `=cmd|'/c calc'!A0` доезжал в CSV без
кавычек. Перед опасным первым символом теперь ставится апостроф; отрицательные
числа не трогаются, чтобы сортировка не сломалась.

**5. Светофор клиента не показывал причин** · `4369c59`

Выдача по одному клиенту возвращала строку без причин — блок не показывался ни
разу. Там же: действия в карточке стирали набранные, но не сохранённые договор,
чек и границы работ.

**6. Нецелевой лид выглядел лучшим в списке** · `6e99077`

Автооценка сравнивала качество с несуществующими значениями. Лид, помеченный
нецелевым, набирал 90 из 100.

**7. Рубли складывались с долларами** · `6a2b907`

ВАЖНО, я ошибся раньше: я говорил, что он пишет только в `docs/`. На самом деле
он пишет ещё и в:

```
public/articles.seed.json

```

То есть при запуске **перезапишет запасную копию статей** содержимым от
07.07.2026, зашитым в него намертво. Запустить его случайно нельзя — в
`package.json` его нет, — но держать в репозитории скрипт, способный затереть
статьи, стоит осознанно. Удалять без вашей просьбы не стал.

**Внешние картинки в статьях по любому `https://`** — так задумано.

**Смоук-тесты Meta CAPI проверяют строки в исходниках, а не поведение** — при
рефакторинге упадут на переименовании. Это заявленное свойство, не ошибка.

## Часть 7. Как продолжить

1. Взять пункт 1 из части 3 — типы. Чистая работа по коду, проверяется
   `npm run check`, ничего не ломает на сайте.
2. Затем пункты 2 и 3 — миграции. Я готовлю SQL, вы применяете в консоли D1 по
   одной команде.
3. Локальный пароль админки — `admin` (`vite.config.ts:23`), к production он
   отношения не имеет.
4. `npm run check` на Windows иногда падает с `Assertion failed: !(handle->flags
   & UV_HANDLE_CLOSING)` — плавающий сбой Node, а не код. Перезапустить. Если
   сбой пришёлся на `generate:pages`, `dist` остаётся неполным — помогает
   `npm run build` отдельно, затем `npm run check`.
