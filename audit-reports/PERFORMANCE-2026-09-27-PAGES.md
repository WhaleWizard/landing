## Браузерные сценарии для общего прогона

1. Блог: выбрать тему, ввести поиск из двух слов, открыть материал, вернуться. Должны сохраниться тема/поиск/позиция; смена только query по ссылке или history должна применить новый набор фильтров.
2. Блог и кейсы: раскрыть фильтры в середине страницы — URL меняется, прокрутка остаётся на месте.
3. Словарь: найти CPQL, раскрыть его, нажать связанный CPL. Поиск очищается, связанный термин раскрывается и доступен.
4. Холодный вход в кейс с ZIP/контактной ссылкой в тексте: предупреждение/SPA-переход должны работать после первой загрузки lazy-компонента. В текущем build-snapshot ZIP не найден — для этого пути нужен локальный fixture, без отправки реальных данных.
5. Отзывы: CMS-набор длиннее fallback, мобильные стрелки и autoplay доходят до всех реальных карточек.
6. Калькуляторы: три режима, пустые/заполненные значения, decimal comma, открытые select, закрытие диалога Escape и возврат фокуса.
