## 2. Проверка кода: как работает автовыкладка по таймеру (Технический аудит)

В коде сайта **уже реализована и проверена тестами** (`scripts/publish-schedule.test.js`) нативная система отложенных публикаций:

1. **База данных D1:** Поле `published_at` хранит точное время в UTC.
2. **Edge-фильтрация (`functions/_lib/articles.ts:40`):**
   ```ts
   export function isPublishedArticle(article: Article, nowIso = new Date().toISOString()): boolean {
     if (article.status === 'draft') return false;
     if (article.publishedAt && article.publishedAt > nowIso) return false;
     return true;
   }
   ```
   Если `publishedAt` находится в будущем относительно текущей секунды, статья **100% невидима** на сайте, в списках блога, в sitemap.xml и для роботов.
3. **Автоматическое истечение кэша (`functions/_lib/cache.ts:20`):**
   Cloudflare Edge динамически рассчитывает заголовок `s-maxage` ровно до секунды выхода ближайшей запланированной статьи. В момент наступления времени статья **появляется на сайте сама без пересборки и без ручного деплоя**.
4. **Случайные интервалы времени:**
   Время рассчитывается в часовом поясе владельца (Ташкент, UTC+5) с разбросом минут (например, 11:24, 13:45, 15:18, 16:50, 18:12, 19:35) и переводится в UTC для базы.
