## Журнал (02.10.2026)

- F-026 · fixed (UI, свой файл) · AdminFinance.tsx · `withInvoiceStatus`: статус «оплачен» в форме подставляет дату оплаты (сегодня по серверу, если пустая), в форме появилось поле «Оплачен» (type=date) только при статусе «оплачен»; другой статус снимает paid_at. Серверная половина (finance.ts save_invoice: paid_at = today при status=paid без даты, NULL иначе; разовый SQL для старых записей) — стык admin-api-money.
- F-037 · fixed · AdminFinance.tsx · общая `profitByCurrency(received, spent, taxRate)` для плитки и таблицы «По месяцам»: перебор объединения валют, налог только по валютам с приходом; месяц с одними расходами показывает «-300 USD», а не «—».
- F-027 · fixed · AdminLeads.tsx · `parseDealValue` поверх `parseDecimalInput` (как остальные денежные поля): «1,234.56», «1.500,50», «1 500,50», «$1,234.56» читаются, пустое — null; нечитаемая строка — запрос не уходит, ошибка у карточки (saveLead) / notify (convertToClient до создания клиента). В onChange убран `.replace(',', '.')`, черновик остаётся строкой.
- F-035 · fixed · AdminLeads.tsx · `advanceStage(current, target)` по порядку new→contacted→discovery→proposal: быстрые действия двигают только вперёд, закрытые (won/lost/archived) не трогают; «Отправил КП» из «Обсуждения» переводит в «Предложение».
- F-066 · fixed · AdminLeads.tsx · плитки «Просрочено / На сегодня / Без следующего шага» ставят фильтр и `setView('list')` (режим сохраняется в localStorage существующим эффектом).
- F-067 · fixed · AdminLeads.tsx · `quickActionDue(current, kind, now)`: «Связаться сегодня» — пустой, прошедший или назначенный на другой день срок → сегодня 18:00 (после 18:00 — ближайший круглый час, не позже 23:59); срок сегодня впереди остаётся. «Подготовить предложение» — пустой/просроченный → сегодня 12:00 по тому же правилу, будущий не трогается.
- F-034 (стык от admin-api-money) · сделано · AdminLeads.tsx · подсветка «Просрочено» в списке только у открытых этапов (`isOpenStage`); CrmBoard.tsx — вместе с F-040.
- F-030 · fixed · CrmAnalytics.tsx · у RankedBars появилось `display?: string`; «Откуда выигранные сделки» передаёт `value: row.value` (число сделок в formatMoney больше не попадает), строка без суммы подписана «сумма не указана» (или «сумма в другой валюте», если сервер отдаст `otherCurrencyDeals`) и остаётся на минимальной полосе 2%. SQL `other_currency` в sourceRows (crm-analytics.ts) — стык admin-api-money, без него работает подпись «сумма не указана».
- F-029 (стык от admin-api-money) · сделано · CrmAnalytics.tsx · тип totals: openValue/wonValue `number | null`; подписи плиток «В работе»/«Выиграно» через `valueCoverage(priced, withoutValue)`: «Сумма — по 5 сделкам; у 3 сумма не заполнена».
- F-031 · fixed · caseFromClient.ts · каждое отношение по парам месяцев: cpl — расход+заявки, ROMI — расход+выручка, конверсия — продажи+заявки; без пар → null; в результат добавлено `ratioGaps: { cpl, romi, conversion }` с подписями месяцев. Вывод строки «Цена заявки посчитана без января: нет расхода» в CaseBuilderDialog.tsx — стык (чужой файл); существующие тесты case-from-client проходят.
