## Находки первого прохода

1. Отчёт считал черновик с датой и ещё не вышедшую публикацию за сегодняшний день. Проверка теперь учитывает статус и точное время.
2. Календарь CRM смешивал пояс браузера с Ташкентом. Сетка, выбранная дата и время напоминания теперь согласованы.
3. Старое время SQLite без суффикса пояса могло сдвинуться в браузере. Некорректные старые даты выводятся в списке без срока.
4. Просроченный шаг за сегодня отмечался в сводке и терял подсветку в клетке. Оба места теперь используют один критерий.
5. После смены месяца боковая панель могла остаться на дате прошлого месяца. Выбор и открытая сетка синхронизированы.
6. Сделка на нулевую сумму теперь показывает сумму в карточке календаря.
7. Убрана циклическая связь типов между календарём и экраном заявок. Календарь передаёт идентификатор сделки, экран открывает карточку.
8. Редактор теперь возвращает контролируемый ответ на JSON `null`.
9. Дела на выбранный день показываются по времени.
10. В календаре можно раскрыть весь список сделок без срока.
11. API клиентов возвращает 400 на неправильное тело запроса и недопустимый идентификатор.
12. Сохранение карточки после удаления клиента возвращает 404 вместо ложного подтверждения.
