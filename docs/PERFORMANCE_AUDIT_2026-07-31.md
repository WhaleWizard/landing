# Production JavaScript audit — 2026-07-31

## Причина проверки

PageSpeed на текущем production повторял рекомендацию «Удалите неиспользуемый код JavaScript» с ожидаемой экономией примерно 61–82 КиБ на главной, блоге и статьях.

## Что было в production до изменений

Общий HTML принудительно загружал три JavaScript-ресурса до выбора маршрута:

| Ресурс | Raw | Передано gzip |
|---|---:|---:|
| `index-Brtp4oDu.js` | 228 770 B | 75 214 B |
| `vendor-DZOa608X.js` | 228 715 B | 74 818 B |
| `motion-o3NMevU8.js` | 101 931 B | 33 887 B |
| Итого | 559 416 B | 183 919 B |

Причина: страницы и часть тяжёлых визуальных компонентов попадали в общий entry, а отдельный Motion chunk был указан как общий `modulepreload`.

## Что изменено

- Все страницы, включая Home, загружаются через `React.lazy`.
- Крупные секции главной загружаются отдельно и по необходимости.
- Cookie manager и плавающий Whale Navigator вынесены из entry; навигатор появляется после первого взаимодействия.
- Admin, Tiptap, каталог кейсов, словарь, калькулятор и Radix Select остаются в отдельных маршрутных или функциональных chunks.
- Motion больше не указан в HTML как общий `modulepreload`.
- MUI удалён из публичных импортов; наличие пакета в `package.json` само по себе не добавляет его в production bundle.

## Результат локальной production-сборки

Общий HTML загружает только entry и vendor:

| Ресурс | Raw | gzip |
|---|---:|---:|
| `index-*.js` | 42 960 B | 14 620 B |
| `vendor-*.js` | 228 715 B | 74 950 B |
| Итого | 271 675 B | 89 570 B |

Общий стартовый JavaScript уменьшен примерно на 288 КБ raw и 94 КБ gzip — около 51% относительно текущего production. Маршрутные chunks загружаются только там, где нужны.

## Контроль после deploy

- Повторно запустить Mobile и Desktop в админ-разделе PageSpeed после прогрева нового Cloudflare-кэша.
- Проверить конкретные URL из исходного отчёта: `/`, `/blog/` и две тяжёлые статьи.
- Если аудит всё ещё показывает общий ресурс, записать его точный URL и `wastedBytes`; не удалять код по названию пакета без проверки coverage.
- Не переносить обратно Motion, Admin, Tiptap, словарь или калькулятор в общий entry ради удобства импорта.
