# SEO

Стратегия целиком — `docs/SEO_STRATEGY.md`: карта поисковых намерений, формулы заголовков, правила
GEO/AEO и план статей. Семантическое ядро — `docs/seo/semantic-core.csv`.
Этот файл — короткие правила для отдельной статьи.

## Главное правило

В заголовке — слова клиента, не термины специалиста. Клиент ищет «таргетолог», «реклама в инстаграм»,
«продвижение приложения»; «performance-маркетинг» и «атрибуция» он не печатает. Термины уходят в
подзаголовки и текст, где доказывают квалификацию.

## Для каждой статьи определить

- Search Intent — что человек хочет сделать после прочтения
- Primary Entity — главная сущность материала
- Supporting Entities — связанные сущности
- Information Gap — чего нет у других
- Natural internal links — минимум три связанные статьи, анкор объясняет пользу
- FAQ questions — вопросы, которые реально задают
- Clear title and description

## Обязательный минимум в тексте

- Краткий ответ в начале: 40–60 слов. Это то, что вытащит ИИ-ответ и прочитает человек.
- Структура: заголовки, списки, таблицы. Читаемость для человека и для машины совпадают.
- Практические сценарии, ограничения, ошибки, FAQ.
- Ссылка на подходящую услугу — одна, к месту.

## Чего не делать

- Не копировать структуру конкурента. Анализ конкурентов — только чтобы сделать лучше и иначе.
- Не создавать отдельную страницу под каждую формулировку запроса: одна страница закрывает кластер.
- Не менять дату публикации ради свежести.
- Не придумывать числа: цену, CPL, ROAS, «в среднем по рынку».
